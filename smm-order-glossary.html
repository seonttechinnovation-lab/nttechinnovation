SMM Order Glossary: 12 Terms Indian Resellers Should Know

Order pages on social media panels are full of short labels that nobody explains. Here is what each one usually means, so you can read a service description and know what you are buying. If the whole idea of a panel is new to you, start with this guide on what an SMM panel actually does.

Service ID
The number the panel uses for one specific product. Two services that look the same can behave very differently, so always note the ID.
Min / Max
The smallest and largest quantity you can order in one go.
Start count
The number of likes, views or followers the post had when the order began. It is how you check delivery later.
Drip-feed
Splitting one order into runs spread over time instead of delivering everything at once.
Runs and interval
With drip-feed, runs is how many batches and interval is the gap between them in minutes.
Refill
A promise to top up drops within a set number of days. No refill means drops are not replaced.
Drop rate
How much of the delivered quantity tends to disappear later. Lower is better.
Partial
The panel delivered only part of the order and refunded the rest to your balance.
Canceled
Nothing was delivered and the full amount went back to your balance.
In progress / Processing
The order is running. Processing often means it is queued with the provider.
Average time
A rough delivery time based on recent orders, not a guarantee.
API key
A private key that lets software place orders on your account. Treat it like a password.

How to use this list

  • Read the service description and match every label to the meanings above.
  • Write down the start count before you place an order.
  • Prefer services with refill if you need the numbers to last.
  • Test with the minimum quantity first.

I keep these notes handy when ordering on SMMYodha, but the terms are the same on almost every panel.
